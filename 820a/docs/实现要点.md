# 实现要点（820A）

## 1. 相机与 AVM 视角

820A 车机的全景影像由厂商 AVM 服务输出，应用侧通过以下方式取得画面：

| 相机 ID | 用途 |
|---|---|
| `Camera.open(0)` | AVM 后视输出（流媒体后视镜使用） |
| `Camera.open(2)` | AVM 主输出（侧视浮窗 / 后侧方使用） |

- 预览格式：`NV21`，`1280×724`；
- 视角切换通过厂商接口：

```java
// 8 = 四路分屏(TL 前 / TR 后 / BL 左 / BR 右)
// 17 = 2D 后视   21 = 窄路   22 = 3D 环绕
avm.setAvmDisplayMode(mode);
avm.setCmdControlParameters(...);
```

- Camera1 打开后若视角未生效，用 Camera2 打开-关闭一次作为兜底（`applyModeViaCamera2`）；
- 原厂 360 占用检测：`dumpsys media.camera` 中 2 号相机是否有非本应用的客户端，
  有则让位（不覆盖原厂界面）。

## 2. 车辆状态检测

所有状态通过 **ADB 本机回环**（`127.0.0.1:5555`）执行 `dumpsys` 获取，
避免依赖 `android.car` 权限：

```bash
dumpsys car_service | grep -E 'lastEvent: ?Property=(BCM_LRTURNLAMP_ACTIVE_ST|BCM_(L|R)TURNLAMP_ST|VCU_CURRENT_GEARLEV|AVM_DISPLAY_MODE|SCU_BSD_(LEFT|RIGHT)_WARNING)'
dumpsys window | grep -E 'mCurrentFocus|mResumedActivity'
```

| 属性 | 含义 |
|---|---|
| `BCM_LRTURNLAMP_ACTIVE_ST` | 转向灯激活状态（`[左, 右]`，稳定值） |
| `BCM_LTURNLAMP_ST` / `BCM_RTURNLAMP_ST` | 左右转向灯（随闪烁变化） |
| `VCU_CURRENT_GEARLEV` | 档位：1=D 2=N 3=R 4=P |
| `AVM_DISPLAY_MODE` | 当前 AVM 模式 |
| `SCU_BSD_LEFT_WARNING` / `SCU_BSD_RIGHT_WARNING` | 盲区有车（0/1） |

- 转向灯巡检 250ms，汽车属性 + 前台包名 800ms，相机占用 1.5s；
- 解析失败时**保持上一轮状态**，避免 dumpsys 抖动造成假边沿；
- 熄灭去抖 2.5s，规避转向灯闪烁间隙误关浮窗。

## 3. 浮窗渲染

- 浮窗为 `TYPE_APPLICATION_OVERLAY`，内容为 `TextureView`；
- 画面裁切/缩放/镜像通过 `TextureView.setTransform(Matrix)` 完成：

```java
// 旋转 90°：窗口尺寸交换为 540×960，并对 TextureView 设置 setRotation
// 水平翻转：postScale(-1, 1, cx, cy)，旋转 90° 时不叠加
matrix.postScale(scale, scale, cx, cy);
matrix.postRotate(rotate, cx, cy);
matrix.postTranslate(dx, dy);
```

- 窗口尺寸变化只在切换方向时重建一次，避免每帧 `updateViewLayout` 造成卡顿。

## 4. 后视镜

- 独立浮窗，`Camera.open(0)` 后视画面；
- 支持拖动、边缘缩放、双击编辑、缩放按钮（1.0×~2.0×）、锁定；
- 显示条件：已开启 + D 档（调试模式例外）+ 桌面 + 非设置页 + 无侧视 + 非倒车 + 原厂 360 未占用；
- 转向灯亮（单边）时让位给侧视，双闪时保持显示；
- 盲区有车时左右两侧显示红色渐变竖条。

## 5. 盲区提示

- 数据源：`SCU_BSD_LEFT_WARNING` / `SCU_BSD_RIGHT_WARNING`；
- 后视镜：左右两条 14dp 竖条（单侧横向渐变 + 上下淡出）；
- 侧视浮窗：底部「⚠ 注意盲区」红色圆角条，属性动画闪烁（1.0 ↔ 0.18）；
- 两个「盲区提醒」开关分别控制两处提示。

## 6. 功耗

- 空闲（轮询开启、无浮窗）实测约 0.7%（`dumpsys cpuinfo`）；
- 主要开销是 `dumpsys car_service` 子进程；关闭「ADB 轮询」可完全停止；
- 所有 ADB 调用均在后台线程，主线程不做阻塞操作。

## 7. ADB 授权

- 应用内置专用 ADB 密钥（`res/raw/adb_key.pem`），随安装包分发，仅用于本程序连接本机 5555；
- 首次连接车机会弹出配对确认，确认后即可长期使用；
- 该密钥是"分享安全"的专用密钥，不包含任何个人密钥。

> 注意：任何拿到安装包的人都可获得该私钥，因此它只应作为本程序的专用密钥使用。
