# P7 打灯转向辅助 v1.207（分享安全版）修改说明

## 一、问题结论（为什么原来没有画面）

原版 v1.46 在 8155 车机上使用 **Camera2** 打开摄像头；而你这台 820A（E28，Android 9 / API 28）的框架里：

```
config.disable_cameraservice = true
```

该属性会让 `android.hardware.camera2.CameraManager.getCameraIdList()` 直接返回空数组，
所以原程序一直走「未发现可用摄像头 / no camera device」分支，永远拿不到画面。

原厂 `xp_CarCamera` 在 820A 上根本不用 Camera2（`CameraFactory.isUseCamera2()` 只有 `au8295_xp` 才为 true），
而是走 **Camera1**：

- `Camera.open(2)` 打开 2 号虚拟摄像头（AVM 输出）；
- 预览 1280×720 / NV21；
- 视角切换用厂商扩展 `Camera.Parameters.setAvmDisplayMode(int)` + `Camera.setCmdControlParameters(Parameters)`。

原版 v1.46 的 `sendAvmMode()` 反射的是 Camera2 的 `CameraManager.getCmdControlParameters()`，
820A 上没有这个接口，所以既没画面、也没能换视角。

## 二、最终实现（v1.207）

### 1. Camera1 预览通路（核心）

新增 `Camera1Preview`（独立 dex 注入，不改原逻辑）：

- `Camera.open(2)` → 1280×720 NV21 → `setPreviewTexture` 画到浮窗 TextureView；
- 反射调用厂商 `setAvmDisplayMode` / `setCmdControlParameters` 下发视角；
- 打开前记录当前 AVM 视角（`getCmdControlParameters().getAvmDisplayMode()`），
  关闭浮窗时先恢复该视角再释放摄像头，避免把原厂窄道/360 的画面顶成后视；
- 下发视角前再次检查原厂是否占用摄像头，占用则跳过；
- 摄像头被占用时 1 秒后自动重试（最多 3 次）。

### 2. 视角选择：四宫格 + 单象限裁切

实测 820A 的 AVM `display-mode`：

| 值 | 画面 |
|----|------|
| 8  | 四宫格：左上=前、右上=后、左下=左、右下=右（原始鱼眼） |
| 16/17/18/19 | 前/后/左/右（AVM 处理过的 2D 画面，已被裁切） |
| 21 | 3D 环视（原厂窄道 BEV 用的值） |
| 22 | 3D BEV |

左右打灯都用 **mode 8**，再把 TextureView 做 2 倍裁切，只显示左下（左灯）/右下（右灯）象限，
这样得到的是**原始鱼眼**单侧画面，并正好铺满 16:9 浮窗。

### 3. 与原厂 360 / 窄道全景共存

- **双闪**（左右转向灯同时亮）时完全不触发左右浮窗：信号监听层忽略双闪边沿，弹窗前还会强制刷新并等待 120ms 复核一次双闪状态；流媒体后视镜保持显示。
- 原厂 360 全景 / 「窄道激活全景影像」正在占用 2 号摄像头时：
  - 立即关闭本程序浮窗并释放摄像头；
  - 原厂关闭后，如果转向灯还亮着，自动恢复本程序浮窗；
- 收到转向灯信号后**立即**打开（不再人为延迟），但浮窗在画面就绪前保持透明，
  做到「窗口和画面同时出现」；
- 不再做车速限制（v1.65 的 <15km/h 让位逻辑已取消）。

### 4. 界面与其它

- ADB 端口默认 **5555**（这台车 adbd 只监听 5555）；
- 浮窗默认贴近屏幕顶部（y=90）；
- 删除「摄像头预览选择」入口（Camera2 已禁用，无法修复）；
- 删除「右浮窗对齐左浮窗」；
- 「还原浮窗设置」保留原功能，并把左右两侧位置都重置到左上角；
- 新增两行三列 6 个按钮：还原浮窗设置 / 浮窗靠左上 / 浮窗靠左下 / 浮窗靠右上 / 浮窗靠右下 / 浮窗靠两侧；
- 使用说明 5 条（第 1 条：请在车辆设置中关闭「转向激活全景影像」）。

## 三、安装与使用

1. 卸载旧版（签名不同，直接覆盖会失败）：`adb uninstall com.xiaopeng.qa.camera`
2. 安装：`adb install P7打灯转向辅助_v1.207_分享安全版.apk`
3. 授予相机、悬浮窗权限：
   `adb shell pm grant com.xiaopeng.qa.camera android.permission.CAMERA`
   `adb shell appops set com.xiaopeng.qa.camera SYSTEM_ALERT_WINDOW allow`
4. 车辆设置里关闭「转向激活全景影像」，避免原厂和本程序同时抢 2 号摄像头。
5. 打开「打灯联动：开启」，程序会通过内置 ADB 密钥连接 `127.0.0.1:5555` 轮询转向灯。
6. 打左/右转向灯 → 浮窗显示对应侧鱼眼；关灯 → 自动关闭并释放摄像头。

## 四、已知限制

- 依赖原厂 AVM 的 2 号摄像头输出；原厂 360 / 窄道全景占用时会自动让位（这是设计行为）。
- 四宫格裁切按 16:9 浮窗设计；浮窗被拖成其它比例时画面会拉伸。
- **不支持投射到仪表盘**：仪表（ICM）不是 Android 显示设备，而是通过 SOME/IP 连接的外部模块，
  Android 侧只有 `ICM_*` 数据类属性，没有视频/显示接口；第三方应用无法把画面送到仪表。
  如果车辆设置里有「仪表显示摄像头」之类的原厂开关，只能用它。
- 修改版使用自签名证书（CN=P7 Camera Assist），不能覆盖安装原作者/你之前签名的版本。
- APK 内置了用于本机 5555 调试的 ADB 私钥（res/raw/adb_key.pem），拿到安装包的人可以在车机上获得
  shell 权限，请勿外传；如需分享，建议先用自己生成的密钥替换后重新签名。

## 五、v1.76~v1.84 修复与优化记录

### 关键修复

1. **原厂占用时不再下发任何 AVM 视角**（修复“原厂画面偶发变后视”的根因）。
   实测日志证明：当原厂 360 也在用 2 号摄像头时，本程序作为第二个客户端下发的任何
   `display-mode`（包括“恢复原厂视角”）都会被 HAL 翻成 17（后视），反而把原厂画面顶掉。
   现在只在“原厂未占用”时才下发视角；关闭浮窗时只释放摄像头，不再回写视角。
2. **裁切基准改为浮窗实际尺寸**。原来按“屏幕宽度×0.4”计算，用户拖动缩放过浮窗后
   四宫格裁切会错位；现在按 `LayoutParams.width/height` 计算，任意窗口尺寸都能正确取单象限。
3. **帧探针缺陷修复**。关闭调试帧探针后，“无帧自动回退视角”会误判为无画面并切到 18/19；
   已移除该自动回退（mode 8 实测稳定），避免中途切换视角。

### 健壮性

4. 注册 `Camera.setErrorCallback`：摄像头被抢占/被 HAL 断开时自动释放并重试。
5. `SignalGate` 巡检线程增加“代次”控制，Service 销毁/重建时不会残留两个轮询线程。
6. `onDestroy()` 调用 `SignalGate.detach()`，Service 停止后不再空转。
7. ADB 链路异常时（exec 返回 null）暂停主线程的补查，避免主线程被长时间阻塞。
8. 隐藏/显示浮窗时同步切换 `FLAG_NOT_TOUCHABLE`，透明阶段不拦截点击；显示时 120ms 淡入。
9. 重试用尽、预览超时等异常兜底：把浮窗恢复为可见，避免留下“看不见的窗口”。

### 性能

10. 弹窗判断只读缓存，主线程不再执行 shell（原厂占用 500ms、双闪/转向 1000ms 轮询）。
11. 反射得到的 Field/Method 全部缓存复用。
12. 移除调试帧探针（不再注册预览回调、不再算亮度）。

### 日志与维护

13. 删除 App 内日志功能：`serviceLog`/`appendLog` 置空，隐藏“状态日志”与“清空日志”区域，
    辅助类日志开关关闭（`DEBUG_LOG=false`），不再产生日志开销。
14. 删除不再使用的 `sPendingOpen`/模式回退状态机，打开/释放逻辑更简单。

## 六、流媒体后视镜（v1.85 新增）

- 开关位置：「打灯联动」按钮同一行右侧，显示「流媒体后视镜：开/关」。
- 画面来源：**0 号后视摄像头**（默认），不修改 AVM 的 display-mode，
  因此不会和左右打灯浮窗（2 号 AVM 摄像头）、原厂 360 抢视角。
- 默认外观：**750×265，位置 (700, 75)**（左侧导航卡片右缘≈695 与右侧竖线导航条左缘≈1452 的正中，高度与导航卡片一致）。
- 平时浮窗上不显示任何文字提示；进入编辑模式后才显示操作说明（点说明文字也可退出编辑）。
- 画面先按浮窗**宽度**等比缩放（不改变原画面比例），再按高度**贴顶裁剪**（保留上部、裁掉下部），适配浮窗；
  拖动窗口边缘改变大小时画面同步重新缩放，不变形、不会溢出窗口。
- 右上角 **✕ 关闭按钮平时隐藏**，点击画面后显示 3 秒；点 ✕ 关闭后视镜并同步关闭设置里的开关。
- 所有浮窗（左右侧视、流媒体后视镜）都改为**圆角**：侧视浮窗用不透明面板色四角遮罩（并修正了自定义 View 默认不绘制的问题），实测四角已圆。
- 操作方式与侧视浮窗一致：
  - 单指拖动：移动窗口位置（松手保存）；
  - 双击：进入编辑模式；
  - 编辑模式：单指平移画面、双指缩放、拖动四边黄色手柄调整窗口大小；
  - 再次双击：退出并保存；
  - 也可以直接点浮窗左上角的提示文字进入/退出编辑模式（车机慢屏上更好按）。
- 「还原浮窗设置」会同时把后视镜的位置/大小/画面恢复到默认（不影响开关状态）。
- 设置页布局：打灯联动单独一行 → 6 个位置按钮 → 流媒体后视镜与锁定开关并排一行。
- 开关状态保存在本地，重新打开 App 或服务重启后会自动恢复浮窗。
- 设置里有「锁定后视镜位置/大小」开关（开启后按钮变金色），锁定后拖动/编辑都不会改变位置和大小，只保留点画面显示 ✕。
- 实测发现 0 号摄像头同样受 AVM display-mode 影响：侧视浮窗把模式切到 8（四宫格）后，后视镜会变成四格画面。
  因此后视镜增加了自动让位：
  - 打灯侧视浮窗打开时，后视镜自动收起，灯灭后自动恢复；
  - 原厂 360/窄道占用 2 号摄像头时，后视镜同样自动收起，原厂关闭后自动恢复；
  - **倒车**（档位 R）时后视镜自动收起，倒车影像界面不受影响；退出倒车后自动恢复，并把 AVM 设回后视视角。
- 后视镜单独显示时不再定期检查视角（按用户要求去掉），仅靠“倒车/侧视收起后重新显示时重开会话”来恢复视角。
  即使侧视浮窗短暂占用把视角改成了四宫格，也会自动改回后视，不会停留在四格画面。
